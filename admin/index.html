پنل سایت

برای ذخیره‌ی تغییرها روی گیت‌هاب، یک بار «کلید دسترسی» را وارد کن. کلید فقط در همین مرورگر می‌ماند.

کلید دسترسی را از کجا بسازم؟
  1. در گیت‌هاب برو به ساخت Fine-grained token.
  2. یک اسم بده (مثلاً panel) و در Expiration مدت دلخواه را انتخاب کن.
  3. در Repository access گزینه‌ی Only select repositories و ریپوی سایت را انتخاب کن.
  4. در Permissions ← Repository permissions، گزینه‌ی Contents را روی Read and write بگذار.
  5. Generate token را بزن، کلید را کپی کن و این‌جا بچسبان.
